# Nepal map geometry

Source: https://github.com/opentechcommunity/map-of-nepal/blob/master/nepal.geojson
License: CC BY 4.0, attribution displayed below map. Source metadata cites MOFAGA government datasets. Retrieved 2026-09-21.

Seven province polygons are projected together with Web Mercator, uniformly fitted into a 760×400 SVG, preserving geographic aspect ratio. Detail is simplified only to 0.12 SVG pixels. No invented boundary or internal lines remain. Kathmandu (85.3240 E, 27.7172 N) and Pokhara (83.9856 E, 28.2096 N) use this same projection. The curved delivery connector remains illustrative, not a road alignment or coverage claim.
